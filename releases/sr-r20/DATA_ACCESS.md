# Obtaining inputs and choosing a reproducibility level

For public aggregate checks and seven plot regenerations, no private input is required. Use docs/REPRODUCIBILITY.md in the repository. The optional eighth plot (Supplementary Fig. S3) needs authorized per-sample SHAP arrays/features. Its fixed author figure is included, but a hash check of that figure is not SHAP recomputation.

Obtain highD, uniD, and exiD from their named leveLXData pages linked in DATA_LICENSES.md; cite each dataset's preferred publication shown there. NGSIM: FHWA, Next Generation Simulation Vehicle Trajectories and Supporting Data, official catalog linked there. MiTra: dataset DOI 10.25532/OPARA-881; descriptor https://doi.org/10.1038/s41597-025-05472-0. ETRI: Korea Electronics and Telecommunications Research Institute, 2019 trajectory data, public portal entry15041797; request access under the provider agreement. EMT: AV-Lab dataset, excluded from main study. Scientific Reports sharing requirements do not grant third-party redistribution rights.

For historical R17 code in a disposable copy, expected source input CSVs are `data/processed/{highD,NGSIM,MiTra,ETRI,uniD,exiD}_gt_3s.csv` under this release root. Raw candidate-check inputs go under `data/raw/<dataset>/`: highD NN_tracks.csv + NN_tracksMeta.csv; NGSIM trajectories-0400-0415.csv / -0500-0515.csv / -0515-0530.csv; MiTra Data_TN/TN_DAll.csv; ETRI 180906_s2d_l3_NN_crop_pp_lane_crt_lccrt.csv (cp949); uniD NN_final_unid.csv; exiD NN_final_exid.csv. These final uniD/exiD CSVs have upstream transformations not fully certified here.

Do not run historical `run_all.sh` in the original research tree. Reconstructing every raw→event→feature stage is not certified by this release. The exact archived R17 A/B/C drivers are preserved, but training needs licensed data, a fresh run directory and a new recorded code/input freeze. Missing inputs must be an explicit error, never an empty successful score. Use `python releases/sr-r20/reproduce/check_inputs.py --data-root /path/to/authorized/data` to check required H3 inputs without training.
